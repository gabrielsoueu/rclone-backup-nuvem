Política de Privacidade - rclone Backup Nuvem

O rclone Backup Nuvem é um aplicativo de uso pessoal, usado apenas pelo próprio dono das contas.

  • O aplicativo acessa o Google Drive do usuário somente para copiar e manter atualizada uma cópia de backup dos arquivos do OneDrive do mesmo usuário.
  • Nenhum dado é compartilhado, vendido ou enviado a terceiros.
  • Os tokens de acesso ficam armazenados apenas no computador que executa o backup e podem ser revogados a qualquer momento em myaccount.google.com/permissions.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
